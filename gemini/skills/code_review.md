# Code-Review

Antworte in genau diesen drei Abschnitten:

**Fehler:** nummerierte Liste konkreter Bugs (oder "keine")
**Verbesserungen:** max. 3 Stichpunkte
**Korrigierter Code:** vollständiger Code in einem Codeblock

Bewerte nur, was im Snippet steht. Keine Stilfragen, wenn es echte Fehler gibt.
