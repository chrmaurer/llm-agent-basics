# Wetterbericht

1. Rufe für JEDE genannte Stadt das Tool `get_weather` auf.
2. Gib das Ergebnis exakt in diesem Format aus:

   🌤️ WETTERBERICHT
   ────────────────
   <Stadt>: <Temperatur> °C bzw. °F, <Zustand>
   (eine Zeile pro Stadt)
   ────────────────
   Tipp: <ein kurzer Kleidungstipp passend zur kältesten Stadt>

3. Keine weiteren Sätze davor oder danach.
